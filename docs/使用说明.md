# Aster SDK 4.0.0

当前 ABI 为 4.0.0。按系统下载一个包：Windows 用 `.zip`，Linux 用 `.tar.gz`。解压后进入 `aster-sdk`。这个目录里有开发工具、两块板的固件、SD 卡字库和模拟器。

3.x 的应用包不能装到这版固件上，需要用本包重新编译。

## 目录

- `aster` 或 `aster.exe`：编译、烧录、安装应用
- `docs/`：手册
- `apps/`：示例
- `firmware/`：固件镜像和 SD 卡字库
- `simulator/`：在电脑上运行应用

## 安装

Linux 需要本机已有 Python 3.12。

```bash
./aster install --add-path
source ./env.sh
```

Windows：

```powershell
.\aster.exe install --add-path
. .\env.ps1
```

## 烧录固件

镜像从地址 0x0 写入。把 `firmware/sdcard/` 里的内容拷到 SD 卡根目录。

立创 ESP32-S3 实战派：

```text
aster flash firmware/aster-firmware-4.0.0-lckfb-s3.bin --port <串口>
```

微雪 ESP32-S3 3.5 寸：

```text
aster flash firmware/aster-firmware-4.0.0-waveshare-35b.bin --port <串口>
```

## 编译并安装示例

```text
cd apps/hello
aster build --target xtensa
aster deploy dist/xtensa/aster.hello.ast --target xtensa --port <串口> --run
```

## 用模拟器运行

先完成上面的编译。立创竖屏分辨率为 240x320，微雪竖屏为 320x480。

Linux：

```text
simulator/aster-sim apps/hello/dist/xtensa/aster.hello.ast --resolution 240x320
```

Windows：

```text
simulator\aster-sim.exe apps\hello\dist\xtensa\aster.hello.ast --resolution 240x320
```
