# Aster SDK 4.3.0

开发包包含 APP 编译器、命令行工具、示例、手册和开发 Skill。支持 ESP32-P4（riscv）和 ESP32-S3（xtensa）。Windows 包自带 Python，Linux 包需要 Python 3.12。

## 安装

Windows 运行 `aster.exe install`；Linux 运行 `./aster install`，然后按命令输出加载环境。使用 `aster doctor` 检查工具，`aster targets` 查看 CPU 目标。

## 配套固件

```text
aster firmware list
aster firmware download --board osptek-p4-st7102
aster firmware flash --board osptek-p4-st7102 --port COM11
aster firmware flash --board lckfb-s3 --port COM12
```

下载内容固定到固件 Release，并在烧录前校验 SHA256。烧录使用整合镜像，从地址 0x0 写入，包含对应启动与分区数据。设备必须插入 SD 卡；首次开机按屏幕提示联网准备系统资源。升级前保留需要的数据。

## 创建、编译和安装 APP

```text
aster init my-app --template hello --id com.example.hello --target riscv
aster build my-app --target riscv --aot
aster deploy my-app/dist/riscv/com.example.hello.ast --target riscv --port COM11 --run
```

lckfb 使用 `--target xtensa`、对应安装包和串口。安装前返回设备桌面，并关闭独立串口监视器。设备屏幕显示文件接收、校验、安装和结果。需要的资源通过 `app.toml` 的 `assets` 声明打包。

## 桌面调试

```text
aster sim --profile p4 --app my-app
aster sim --profile lckfb --app my-app
aster sim --profile p4 --app my-app --resources path/to/resources
```

首次运行下载并校验独立桌面模拟器，之后使用本地缓存。当前桌面二进制适用于 Windows x64；其他平台可使用模拟器源码。已编译工程按配置读取 dist/riscv 或 dist/xtensa，并自动查找包旁的 resources 目录。可直接指定 --app 包路径。调试模式使用本地字库；支持自定义分辨率、PNG 截图和带系统音效、游戏音效及背景音乐的 MP4 录屏。

模拟器执行安装包中的 WASM，不代表实机 AOT 的帧率和内存表现。完整 API 与工程配置见 [APP 开发手册](app-development.md)。
