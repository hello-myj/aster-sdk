# 2048

滑动合并数字。右上角第一行切换 BGM，第二行切换音效；开关会保存在应用 KV 中。达到 2048 后点屏幕继续，失败后点屏幕重开。

音频是可选能力。设备未启用音频输出时游戏照常运行。ABI 3.4 固件会在 BGM 上混合移动、合并、胜利和失败音效，不会中断音乐。关闭 BGM 后，固件会将已缓存的音效直接混入静音输出，避免每次音效重新打开文件及音频设备。BGM 素材的电平单独降低，四种音效的电平高于 BGM；系统总音量仍统一控制最终输出。退出应用会停止播放并释放音效缓存。

`audio/` 中的音乐和音效由本目录的 `make_audio.py` 生成，均为本项目原创合成音。重新生成需要 Python 3 和 ffmpeg；正常构建只读取已提交的音频文件。
