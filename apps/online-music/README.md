# 在线音乐（ABI 3.10 实机示例）

真正边下载边播放 MP3，不保存整首歌或临时 MP3 文件。原有 Player 文件播放器不受影响。

## 构建与安装

```bash
python tools/build.py apps/online-music --target xtensa
aster deploy dist/xtensa/aster.music.online.ast --port /dev/ttyACM0 --target xtensa
```

设备需匹配的 ABI 3.10 固件、联网及 `audio-stream` 能力。包约 48 KiB，原生绘制适配 240×320 和 320×480。模拟器当前不支持此可选能力，会明确拒绝加载，不能替代实机音频验收。

打开后获取三首示例曲目；点列表播放；底部上一首／暂停继续／下一首；最下方刷新与停止。触摸切歌先关闭旧网络和音频句柄，再重新申请，重复点击不会无限创建会话。后台系统上下拉仍由固件处理。

## 国内音乐源

当前直接访问网易云站点自身使用的 HTTP 接口，开发板直接联网，不借用 PC VPN、代理或转码服务：

- 元数据：`http://music.163.com/api/song/detail/?ids=%5B139774,480580003,441491%5D`
- 播放地址：`http://music.163.com/api/song/enhance/player/url?ids=%5B139774%5D&br=128000`

只使用平台在未登录状态下实际返回的 MP3 URL；要求返回 `code=200`、`type=mp3`、`freeTrialInfo=null`，CDN 主机限定 `.music.126.net`。拒绝无地址、试听受限或不支持编码的曲目。这里“可免费播放”不等于内容可以重新发布或商用授权，不附带音乐文件。曲目版权与可播状态由平台决定；接口不是承诺稳定的第三方开放服务，可能变化或停止，届时应替换源而非破解限制。

示例列表由 MUSIC_IDS 控制（编译期数字 ID 列表，最多8项；小屏最多显示3行，建议不超过3项）。默认仅展示曲目元数据，不自动播放。每次选歌重新获取短期有效链接，不持久化 CDN URL。申请128 kbps，实际返回格式/码率仍由服务端决定。

这里使用 HTTP，无凭据或登录信息，数据不具备 HTTPS 传输保密性；不能把该方式用于账号密码。示例已声明 `tls` 以兼容可能返回的 HTTPS 地址；替换来源时按 SDK HTTP 文档配置可信 CA，禁止关闭证书校验。

## 缓冲与错误

APP 的 MP3 待写块仅2 KiB，部分写入保留尾部。元数据按字节拼出单个 JSON 对象，上限8 KiB，不将整份响应载入内存。音频使用固定32 KiB PSRAM输入环和16 KiB解码窗口；完整内存预算见 [流式音频接口](../../docs/audio-stream.md)。网络与解码投喂按帧推进，静态状态页最多5fps重绘，避免30fps整屏重画挤占网络调度。不在事件回调中等待网络或播放器。

正常 HTTP EOF 才 `finish`，随后等音频 DONE。网络错误直接关闭；首次响应超30秒报错，不无限等候。暂停后仍可接收至固定缓冲满，HTTP 总超时仍为10分钟，长时间暂停后需要重新选曲。无拖动进度功能（流接口不支持 seek）。

日志 `MUSIC streaming rx=... total=... played=... underruns=... eof=...` 用于核实：`played>0` 且 `rx<total`、`eof=0` 才是下载完成前已进入播放。`underruns` 持续增长表示网络或调度未能持续供给，不能把“HTTP请求成功”当作连续播放通过。
